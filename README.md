## 🎯 Objectives

The main objectives of this project are to:

- Download John the Ripper from official website on your windows PC.
- Download Johnny GUI from official website.
- Run the setup file & install Johnny.
- After installation, open Johnny.
- Click on settings & browse and Select John.exe .
- Download the encrypted PDF file to your PC and Browse the PDF file & click on Upload.
- Open Johnny again and Click on ‘Open password file then Click on ‘Start new attack’:.
- Now you can use this password to open your PDF file.
